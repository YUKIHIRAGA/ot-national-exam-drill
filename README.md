# OT National Exam Drill

Open-source toolkit for creating occupational therapy national exam drills and mock examinations from user-provided question datasets.

## Purpose

This project supports educators in generating customized study drills and mock examinations for occupational therapy education.

## Features

- Import question data from CSV
- Randomly select questions
- Specify the number of questions
- Generate a question sheet
- Generate a separate answer key
- Uses synthetic sample data for demonstration

## Quick Start

Python 3 is required.

```bash
python3 generate_drill.py --count 3
